# Reading list

organizers' [joint statement](https://terrytao.wordpress.com/2026/09/28/joint-statement-about-mathathon/).

## Tools

- [PySAT](https://pysathq.github.io/): SAT solvers from Python
- [Lean `bv_decide`](https://lean-lang.org/doc/api/Lean/Elab/Tactic/BVDecide.html): checks SAT certificates inside Lean
- [Uijlen and Westerbaan's search code](https://github.com/bwesterb/ks): public; check its license before reusing any of it
