# AI-use log

The Mathathon asks participants to fully disclose and justify their use of LLMs and to keep chat
histories in the repository. This folder is where they go.

## How to log a session

1. Export the conversation (a share link, or copy the text) into a file named
   `YYYY-MM-DD-topic.md` in this folder.
2. Add a row to the table below: the date, the tool, what it was used for, and how its output was
   checked.
3. If a claim from the conversation enters the explainer, add it to [CLAIMS.md](../CLAIMS.md) with the
   source or script that backs it. An AI answer on its own never counts as a source.
