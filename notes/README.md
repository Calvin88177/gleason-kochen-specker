# Notes

One file per block of the 40-hour plan, named `<block>-<topic>.md` (for example `B-gleason-proof.md`).

Each file starts with:

- **Question:** what the block is trying to understand
- **Answer so far:** in one or two sentences
- **Open points:** what is still unclear

Anything stated as fact goes into [CLAIMS.md](../CLAIMS.md) with its source.
